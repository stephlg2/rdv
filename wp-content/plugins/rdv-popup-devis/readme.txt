Pop-up intelligent avec bouton vers le formulaire de demande de devis. S'affiche selon plusieurs conditions (temps, pages vues, scroll).

== Description ==

Plugin WordPress pour afficher un pop-up intelligent qui redirige vers le formulaire de demande de devis.

**Fonctionnalités :**
* Affichage conditionnel selon plusieurs critères (temps, pages vues, scroll)
* Design moderne et responsive
* Gestion des cookies pour éviter les pop-ups répétés
* Interface d'administration complète
* Accessible (ARIA, clavier, focus)

**Conditions d'affichage :**
* Temps passé sur la page (par défaut : 45 secondes)
* Nombre de pages visitées (par défaut : 2 pages)
* Pourcentage de scroll (par défaut : 50%)

Le pop-up s'affiche si **au moins une** de ces conditions est remplie.

== Installation ==

1. Télécharger le plugin
2. Activer le plugin dans le menu "Extensions" de WordPress
3. Aller dans "Réglages > Pop-up Devis" pour configurer
4. Personnaliser le contenu et les conditions d'affichage

== Configuration ==

1. **Activer le pop-up** : Cocher la case pour activer
2. **URL du formulaire** : URL complète vers votre formulaire de devis
3. **Conditions d'affichage** :
   * Temps sur la page (secondes)
   * Nombre de pages vues
   * Pourcentage de scroll
4. **Durée du cookie** : Nombre de jours avant de réafficher (0 = toujours afficher)
5. **Contenu** : Titre, message, textes des boutons
